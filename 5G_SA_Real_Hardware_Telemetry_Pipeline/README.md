# 📡 5G SA Real Hardware Single-Antenna Telemetry Pipeline

---

> [!NOTE]
> โฟลเดอร์นี้เป็นระบบดักจับและวิเคราะห์สัญญาณคลื่นวิทยุ **Single-Antenna (เสาเดี่ยว - 1 TX / 1 RX)** เหมาะสำหรับการดักจับและวิเคราะห์ค่า RTT ระยะทาง และ SNR บนแบนด์วิดท์ย่านกว้าง 40 MHz (106 PRB) โดยทำงานร่วมกับเครื่องมือดักจับ L1 Telemetry T-Tracer ดั้งเดิม

## 📊 1. พารามิเตอร์เชิงฟิสิกส์วิทยุและโครงสร้างข้อมูล (Extracted Parameters & Shapes)

ชุดข้อมูลวิทยุจริงที่สกัดเรียลไทม์ OTA จะถูกบันทึกลงไฟล์:
📂 **เส้นทางจัดเก็บข้อมูลดิบ:** `/home/beam/.gemini/tmp/demo/srs_dataset_real_hardware.csv`

ข้อมูลที่บันทึกสำหรับรุ่นเสาเดี่ยว ประกอบด้วยคีย์สำคัญดังนี้:

| พารามิเตอร์จริงในไฟล์ CSV | ความหมายและที่มาทางวิศวกรรมวิทยุ | ขนาดและลักษณะข้อมูลจริง |
| :--- | :--- | :--- |
| **`Timestamp`** | เวลาทางวิทยาศาสตร์ขณะบันทึกข้อมูลวิทยุ | `YYYY-MM-DD HH:MM:SS` |
| **`RNTI`** | เลขประจำตัวเครื่องลูกข่าย (CPE) ในระบบ | เลขฐานสิบหก (เช่น `0x1DC6`) |
| **`RTT_Dist_RX0_m`** | ระยะทางสะท้อนของคลื่นวิทยุเสาเดี่ยว (RX0) | ทศนิยมหน่วยเมตร (คำนวณละเอียดระดับอนุวิถี IFFT) |
| **`TA_Distance_m`** | ระยะทางเฉลี่ยที่ได้จาก Timing Advance ของ MAC Layer | ทศนิยมหน่วยเมตร |
| **`RSRP_RX0_dBm`** | กำลังรับสัญญาณวิทยุจริงของเสารับหลัก | ทศนิยมหน่วย dBm (Noise Floor ~ -120 dBm) |
| **`SNR_RX0_dB`** | อัตราส่วนสัญญาณต่อสัญญาณรบกวนสด | จำนวนเต็มหน่วย dB (ย่านปกติ 3 - 35 dB) |
| **`Avg_Mag_RX0`** | ระดับ Magnitude เฉลี่ยบน ADC ของบอร์ดวิทยุ | แรงดันดิจิตอล (Thermal Noise Floor ~ 300-380) |
| **`Raw_IQ_Full_RX0`** | **Complex IQ ดิบแบบครบทุก Subcarrier** ของสัญญาณ SRS | อาร์เรย์จำนวน complex numbers 1536 จุด คั่นด้วย `;` |
