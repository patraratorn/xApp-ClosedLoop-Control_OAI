# 📡 5G SA Real Hardware MIMO 2T2R Telemetry Pipeline
## คู่มือการสกัดและวิเคราะห์คุณลักษณะคลื่นวิทยุ MIMO SRS ดิบระดับกายภาพบน USRP B210 (52 PRB - 10 MHz)

---

> [!NOTE]
> โฟลเดอร์นี้เป็นระบบสกัดข้อมูลคลื่นวิทยุ **MIMO 2T2R (2 TX / 2 RX)** ที่ได้รับการจูนทางฟิสิกส์ให้เสถียรที่สุดเพื่อโครงการวิจัยการคาดการณ์มุมตกกระทบ (AoA) ของทีมวิจัยโดยเฉพาะ โดยทำงานบนแบนด์วิดท์ 10 MHz (52 PRB) เพื่อแก้ปัญหาทางกายภาพด้านขีดจำกัด Sampling Rate ของบอร์ด USRP B210

## 📊 1. พารามิเตอร์เชิงฟิสิกส์วิทยุและโครงสร้างข้อมูล (Extracted Parameters & Shapes)

ชุดข้อมูลวิทยุจริงที่สกัดเรียลไทม์ OTA จะถูกบันทึกลงไฟล์:
📂 **เส้นทางจัดเก็บข้อมูลดิบ:** `/home/beam/.gemini/tmp/demo/srs_dataset_real_hardware.csv`

ข้อมูลที่บันทึกจะล้างสะอาดตั้งแต่บรรทัดแรกและบันทึกคีย์สำคัญทางฟิสิกส์วิทยุ MIMO ดังนี้:

| พารามิเตอร์จริงในไฟล์ CSV | ความหมายและที่มาทางวิศวกรรมวิทยุ | ขนาดและลักษณะข้อมูลจริง |
| :--- | :--- | :--- |
| **`Timestamp`** | เวลาทางวิทยาศาสตร์ขณะบันทึกข้อมูลวิทยุ | `YYYY-MM-DD HH:MM:SS` |
| **`RNTI`** | เลขประจำตัวเครื่องลูกข่าย (CPE) ในระบบ | เลขฐานสิบหก (เช่น `0x1DC6`) |
| **`RTT_Dist_RX0_m`** | ระยะทางสะท้อนของคลื่นวิทยุเสาที่ 1 (RX0) | ทศนิยมหน่วยเมตร (คำนวณละเอียดระดับอนุวิถี IFFT) |
| **`RTT_Dist_RX1_m`** | ระยะทางสะท้อนของคลื่นวิทยุเสาที่ 2 (RX1) | ทศนิยมหน่วยเมตร |
| **`TA_Distance_m`** | ระยะทางเฉลี่ยที่ได้จาก Timing Advance ของ MAC Layer | ทศนิยมหน่วยเมตร |
| **`RSRP_RX0_dBm` / `RX1_dBm`** | กำลังรับสัญญาณวิทยุจริงของแต่ละเสารับ | ทศนิยมหน่วย dBm (Noise Floor ~ -120 dBm) |
| **`SNR_RX0_dB` / `RX1_dB`** | อัตราส่วนสัญญาณต่อสัญญาณรบกวนสดรายเสา | จำนวนเต็มหน่วย dB (ย่านปกติ 3 - 35 dB) |
| **`Phase_Diff_deg`** | **ความต่างเฟสเชิงมุมกายภาพ** ระหว่าง RX0 และ RX1 | ทศนิยมหน่วยองศา (Feature หลักสำหรับโมเดล AoA) |
| **`Avg_Mag_RX0` / `RX1`** | ระดับ Magnitude เฉลี่ยบน ADC ของบอร์ดวิทยุ | แรงดันดิจิตอล (Thermal Noise Floor ~ 300-380) |
| **`Raw_IQ_Full_RX0` / `RX1`** | **Complex IQ ดิบแบบครบทุก Subcarrier** ของสัญญาณ SRS | อาร์เรย์จำนวน complex numbers 768 จุด คั่นด้วย `;` |

## 🛠️ 2. คู่มือปฏิบัติการรันระบบจริงใน 1 คำสั่ง (One-Click Orchestration Guide)

ระบบได้รับการตั้งค่าให้อัตโนมัติ 100% คุณ Beam สามารถสั่งรันและควบคุมแล็บวิทยุจริงด้วยขั้นตอนดังนี้ครับ:

### ขั้นตอนที่ 1: การสั่งรันระบบแบบอัตโนมัติ (Orchestration)
เปิดเทอร์มินัลวิศวกร แล้วรันคำสั่งเดี่ยว:
```bash
cd /home/beam/Desktop/ORAN-ClosedLoop-Control/5G_SA_Real_Hardware_MIMO_2T2R_Pipeline/
bash run_real_hardware_pipeline.sh
```
*   **การทำงานเบื้องหลัง:** สคริปต์จะปิดโปรเซสตกค้างทั้งหมด บูต TMUX session ชื่อ `5g_oran_b210` แล้วสร้างหน้าต่างแยกงาน (RIC, T-Tracer, gNB MIMO, Dashboard) รันเบื้องหลังให้เองทันที! และจะพาคุณ Beam เข้าสู่หน้า Dashboard อักษร ASCII สวยงามโดยอัตโนมัติ

### ขั้นตอนที่ 2: การกระตุ้นสัญญาณต่อเนื่องจากเครื่อง CPE (UE)
เมื่อระบบ gNB บูตเสร็จและเครื่อง CPE (5G UE) เกาะสถานะ `Connected` เรียบร้อยแล้ว **ต้องเปิดทราฟฟิกข้อมูลขาขึ้น** เพื่อบังคับให้ UE ยิงคลื่น SRS ออกมาอย่างต่อเนื่องสม่ำเสมอ:
```bash
# รันคำสั่งนี้บนเครื่องลูกข่าย (CPE) เพื่อกระตุ้น Telemetry
ping -i 0.1 -s 1200 12.1.1.1
```
*(ข้อมูล RTT, Phase, และ Raw IQ ดิบจะหลั่งไหลเข้าสู่ไฟล์ CSV ทันทีแบบเสถียรนิ่งสนิท)*

### ขั้นตอนที่ 3: การปิดและล้างระบบพอร์ตวิทยุอย่างปลอดภัย (Teardown)
เมื่อต้องการปิดการทดลองและคืนพอร์ตวิทยุ USRP B210 ให้รันคำสั่ง:
```bash
bash stop_real_hardware_pipeline.sh
```

## 🔌 3. ตัวแปลงข้อมูลป้อนทีมวิจัย AoA (srs_adapter.py Spec)

📂 **เส้นทางสคริปต์แปลงข้อมูล:**
`/home/beam/Documents/Obsidian Vault/DEMO/AoA_Project/AoA_Project-main/srs_adapter.py`

### วิธีการรันแปลงข้อมูลเพื่อสร้าง Cache:
คุณ Beam สามารถรันสคริปต์ตัวกลางนี้ได้โดยตรงในโฟลเดอร์โครงการ AoA:
```bash
cd "/home/beam/Documents/Obsidian Vault/DEMO/AoA_Project/AoA_Project-main"
python3 srs_adapter.py
```
*   **การประมวลผล:** สคริปต์จะใช้สูตรคณิตศาสตร์ **Complex Linear Interpolation (768 -> 1008 จุด)** และแปลงฟีเจอร์ บันทึกเป็นไฟล์ Cache `.npy` ทั้ง 4 ไฟล์ในโฟลเดอร์ `cache/` (ได้แก่ `real_hardware_phase_X.npy`, `real_hardware_image_X.npy`, `real_hardware_cov_X.npy`, `real_hardware_y.npy`) เพื่อให้ทีมงานนำไปโหลดประเมินผลบน PyTorch ได้ทันที
